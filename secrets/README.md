# ○ secrets/README.md —— 机密外延 E3_ref（阳中阴点 / 圆内环）

> **只写「如何取」，不写值。** 真值在 Vault，体系只留引用名。
>
> 这个文件能被安全地整包发给任何人——因为它里面一个秘密也没有。

## 一、原则

- 本目录不放任何明文密钥、密码、PAT、API Key。
- 所有机密以「引用名」出现在代码与文档中（见 Readme 凭证引用表）。
- 运行期由 Vault 注入环境变量，使用后即弃，不落盘。

## 二、如何取（取用流程）

```
引用名 → Vault 路径 → 取出 → 注入环境 → 运行期使用 → 不写文件
```

## 三、Vault 选型（独立于项目之外）

| 场景 | 推荐 |
|------|------|
| 个人 | 系统钥匙串 / 1Password / Bitwarden / KeePassXC |
| 团队 | HashiCorp Vault / Infisical / Doppler / 云 Secrets Manager |
| 高安全 | HSM / YubiHSM / Thales Luna / 云托管 HSM |

这个仓库里现在没有任何真值可被泄露，也不可能有。

与之配套的约束：

- **引用就写到这一步为止**：需要时留出引用名占位，**不在聊天记录、commits、issues 里出现明文**。

## 五、泄露处置

- 泄露即轮换：在 Vault 中吊销并重签，更新引用映射。
- 不依赖「删除 git 历史」止血，靠换凭证。
- 最小权限：短期令牌、按需授权、可轮换。
